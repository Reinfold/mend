One patch tool for every AI edit format. mend applies AI-written edits — unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON tool calls — to a tree of files.

Built with Node 22 and its standard library only. Deterministic: the same input always gives the same result.

Run it with:

    node main.ts [options] [PATCH]
